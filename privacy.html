Privacy Policy for Mikiyas Planner Sync

Last updated: 30 October 2026

Mikiyas Planner Sync is a personal productivity tool built and used by one person (Mikiyas Aschalew). It collects messages from the owner's own Gmail accounts and Telegram chats into a private planner dashboard. This page explains what it does with Google user data.

What the app accesses

When the owner connects a Gmail account, the app asks for one permission only: read-only access to Gmail (gmail.readonly). It cannot send, delete, or change any email.

What is stored

For recent inbox messages the app stores the sender's name and address, the subject, Gmail's short text snippet, the date received, and a link back to the message in Gmail. It does not store full message bodies or attachments. It also stores the OAuth login tokens that let it keep reading the connected account.

How it is used

The stored information is used only to show the owner a sorted list of mail that needs attention (for example, direct messages, urgent wording, security codes) inside the owner's own planner. Sorting is done with simple keyword rules inside the app.

Sharing

Google user data is not sold, shared, or transferred to anyone, and it is not used for advertising. No person other than the account owner reads it. It is not used to train AI or machine learning models.

Where it is kept

Data is kept in the owner's own private database (Supabase) and processed by the owner's own server (Render). Access is limited to the owner.

Google API Services User Data Policy

Mikiyas Planner Sync's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting your data

The owner can disconnect an account at any time from the planner's control bot, which deletes that account's stored mail and login tokens. Access can also be revoked at myaccount.google.com/permissions.
